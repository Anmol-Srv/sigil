Sigil · retrieval release

The right memory, first.

Sigil recalls facts for coding agents from a local graph. It was finding the right fact and then burying it at rank 4. A Jev decision layer now re-ranks the shortlist before an agent ever sees it — and screens it for text written to hijack that agent. Retrieval stays local and authoritative; every failure path returns the local order untouched.

Read this before believing the numbers

Known limits of this measurement

  • The labels are model-generated, not human-reviewed. The same model that built this system judged which facts were relevant. That is a conflict of interest, and it is the single reason none of these numbers should be quoted as a benchmark.
  • n = 12 queries, one person's store. No confidence intervals. Enough to catch bugs — and it caught four — not enough to make a claim about anyone else's data.
  • Graph promotion is rare: 1 query in 12. Traversal is query-agnostic, so most of what it reaches gets rejected. Expansion earns its place by recall, not by precision.
  • forbidden@5 did not improve. Rank 1 got materially cleaner; by rank 5 the reranker is no better than local at keeping noise out.
